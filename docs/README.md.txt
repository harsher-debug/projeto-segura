# Segura OS

## Visão

Segura OS é uma plataforma imobiliária completa desenvolvida para centralizar todos os processos da imobiliária.

O sistema possui:

- Site Público
- Dashboard Administrativo
- Portal do Cliente
- Portal do Proprietário
- Portal do Locatário
- Portal do Corretor
- Central de Inteligência Artificial

---

## Tecnologias

- React 19
- TanStack Start
- TanStack Router
- TypeScript
- TailwindCSS 4
- Supabase
- React Query

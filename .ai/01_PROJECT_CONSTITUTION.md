# Project Constitution

## Escopo V1
- Site Público
- Área do Cliente
- Área do Locatário
- Área do Condômino
- Área Administrativa

## Regras
- Não criar CRM, ERP, Dashboard ou Financeiro.
- Não duplicar componentes.
- Reutilizar código.
- Trabalhar por sprints.
- Classificar arquivos como MANTER, MOVER, REMOVER ou ANALISAR.
- Nunca remover arquivos classificados como ANALISAR sem aprovação.
- Validar build após cada etapa.
